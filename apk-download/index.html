Features

为“长期在线”而设计

不只是把 bore 打包进 APK，而是补齐移动端后台运行、权限与多通道管理。

多通道并发

每条通道对应一个独立 bore 进程，多个本地端口同时映射，互不干扰、独立重连。

悬浮窗守护

可拖动状态胶囊与通道面板，任意界面查看公网地址并单独启停，不必切回应用。

断线自动重连

进程退出后按 3→30 秒指数退避自动拉起；网络恢复时立即重连，无需手动干预。

前台服务保活

Foreground Service + WakeLock + WifiLock + 电池白名单引导，降低息屏被系统回收的概率。

完整命令能力

local / server 双模式，secret、local-host、远程端口、min/max port、bind-addr 等参数齐全。

实时日志

统一日志面板按通道名标注输出，错误、连接、隧道地址一目了然，便于排查。

Getting started

四步开始使用

首次启动需要授予必要权限；通道参数与本机运行的服务保持一致。

下载并安装

允许文件管理器或浏览器安装未知来源应用，安装完成后打开「Bore 隧道」。

授予权限

允许通知、悬浮窗，并点击「加入电池优化白名单」，保证后台稳定运行。

添加通道

为每个本地服务新增通道：填写本地端口、服务器地址，远程端口可留空自动分配。

全部启动

点击「全部启动」，在通道行、通知栏或悬浮窗中查看生成的公网地址。
